作業系統學習筆記 1

發表於2026-06-01|更新於2026-06-07|資訊工程作業系統
|瀏覽量:

筆者的廢話

這是一篇有關於筆者本人自己做的學習紀錄，除了自用外，也希望能提供幫助給有需要的人～
我將會採取一篇一份觀念的方式，完成資訊類科系學生在大學要完成的作業系統學習。
本人才疏學淺，不排除有觀念錯誤的可能性，如有問題歡迎指正～

直接正文開始！！！

本內容參考書籍：Abraham Silberschatz, Peter Baer Galvin, Greg Gagne. Operating System Concepts (Full Version), 10th Edition, ASIA Edition. John Wiley & Sons, Inc., 2019

什麼是作業系統？

一句話很難定義什麼是作業系統，所以先用幾個常見的例子來說吧：

  • Windows：由微軟公司開發的，用於個人電腦的作業系統（個人電腦作業系統市占率最高）。
  • macOS：由蘋果公司開發的，專用於 Mac 電腦的作業系統。
  • Linux：開放原始碼作業系統核心，許多開發者以此基礎上打包成各式各樣的「Linux 發行版」，用途廣泛。
  • Android：由谷歌公司開發的，基於 Linux 核心開發的，用於大部分手機與平板的作業系統。
  • iOS：由蘋果公司開發的，基於 macOS, Darwin（蘋果公司釋出的開放原始碼作業系統）開發的，專用於 iPhone 與 iPad 的作業系統。

從中我們可以看出，作業系統似乎是和電腦密不可分的一套軟體。
而事實上，作業系統的功能及表達了這一點：

作業系統是連接使用者和電腦硬體之間的橋樑

那作業系統具體有哪些主要功能呢？我們來看看吧：

  • 行程管理
  • 記憶體管理
  • 儲存/檔案系統管理
  • 安全和保護

而剛好，我們將以這四個大方向，去認識作業系統，這些在之後都會詳細說明。

使用者介面

首先，我們可以先來討論一個東西，叫做使用者介面（User interface, UI）。
使用者介面是什麼？
我們可以通過點擊圖片，輸入指令等，來與電腦做「互動」。
相對的，我們也可以從螢幕顯示的文字，喇叭傳出來的聲音，接受到來自電腦的訊息。
而為了簡化我們與電腦之間的溝通成本，系統開發者就要在使用者介面的開發上下一番功夫，讓使用者在操作電腦上更加直覺。

針對現代電腦的 UI，圖形使用者介面（Graphical User Interface, GUI）達到了降低使用者負擔，降低學習成本，讓操作電腦更直觀，增加美觀等需求。
然而在早期，GUI 普及之前，命令列介面（Command-line interface, CLI）則是作為電腦最主要的 UI，其純文字的特點，雖然沒有像 GUI 那麼方便使用者操作，但能更節省電腦資源。
即便到現在，我們的電腦依然可以使用命令列介面（終端機）來操作電腦。

圖形使用者介面：Windows 11 主畫面截圖
命令列介面：Windows PowerShell 1.0 截圖

所以，若要歸納使用者介面是什麼，那就是——

使用者介面是連接著「人」與「機」最直接的方式。

不論是通過主機上的按鈕讓電腦開機，還是用滑鼠點擊桌面上的 icon 打開文件夾，都是所謂的使用者介面。

到目前為止，我們知道了：

  • 常見的作業系統
  • 使用者介面有哪些
  • GUI 和 CLI 的差異

然而，當我們在操作滑鼠（或是鍵盤）時，電腦如何在執行其他程式時（電腦在運行時，一直都是處在一個很忙碌的狀態），還能有時間發現我們正在給它傳遞訊息呢？
